# Exercícios de Correção de Sintaxe XML

## Objetivo

O objetivo destes exercícios é desenvolver a habilidade de identificar e corrigir erros de sintaxe em documentos XML.

## Descrição

Nesta atividade foram analisados diferentes documentos XML contendo erros de sintaxe. O trabalho consistiu em identificar os problemas encontrados e realizar as correções necessárias para que os arquivos se tornassem documentos XML válidos.

## Exercícios realizados

Foram corrigidos os seguintes arquivos:

* **atividade-01.xml** - Cadastro de Livro

  * Correção de tag sem fechamento.

* **atividade-02.xml** - Cadastro de Aluno

  * Correção de atributos sem aspas.
  * Correção da estrutura da tag de idade.

* **atividade-03.xml** - Empresa

  * Correção da declaração XML.
  * Correção do uso do caractere especial `&`.

* **atividade-04.xml** - Pedido de Venda

  * Correção da ordem de fechamento das tags (aninhamento XML).

* **atividade-05.xml** - Cadastro de Produtos

  * Correção de nomes de tags inválidos.
  * Correção de tag iniciada com número.

* **atividade-06.xml** - Sistema Escolar (Desafio)

  * Correção de declaração XML.
  * Correção de atributos.
  * Correção de caracteres especiais.
  * Correção de tags não fechadas.

## Conceitos praticados

Durante a realização dos exercícios foram aplicados conceitos importantes de XML:

* Estrutura correta de documentos XML.
* Fechamento obrigatório de tags.
* Uso correto de atributos.
* Regras para criação de nomes de elementos.
* Uso de entidades XML, como `&amp;`.
* Organização e hierarquia dos elementos.
